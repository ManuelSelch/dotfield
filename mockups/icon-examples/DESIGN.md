# Dotfield Icon Examples

- Goal: show a few browser favicon and iOS home-screen icon directions before selecting a production design.
- Revision: 1
- Status: approved for implementation (Connected field, user-selected)
- Scope: four static, wordmark-free SVG concepts presented at large, favicon, and iOS-like sizes.
- Concepts: connected field, expansion pulse, contested core, and field mark.
- Limitations: examples are inline SVGs in a disposable mockup; no production metadata or assets were changed.
- Approval: user selected Connected field for the browser favicon and iOS Add to Home Screen icon.
